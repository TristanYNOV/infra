# Checklist — Accessibilité

## Objectif du document
Contrôler les exigences d’accessibilité applicables aux interfaces.

- [ ] Navigation clavier complète
- [ ] Labels explicites des champs
- [ ] Focus visible
- [ ] Contrastes suffisants
- [ ] Messages d’erreur compréhensibles
- [ ] Boutons icônes avec `aria-label`
- [ ] Tutoriel utilisateur présent
- [ ] Limites métier liées à l’analyse vidéo documentées
