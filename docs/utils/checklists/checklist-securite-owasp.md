# Checklist — Sécurité OWASP

## Objectif du document
Vérifier les contrôles minimaux de sécurité applicative.

- [ ] Contrôle d’accès (ownership, rôles)
- [ ] Authentification (JWT/refresh/logout)
- [ ] Gestion des secrets
- [ ] Configuration CORS
- [ ] Security headers
- [ ] Prévention injection
- [ ] Validation DTO / inputs
- [ ] Rate limiting
- [ ] Journalisation et alertes
- [ ] Dépendances à jour
- [ ] Images Docker fiables (tags/digests)
- [ ] Gestion des erreurs en prod
