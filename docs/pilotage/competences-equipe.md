# Compétences et montée en compétences

## Objectif du document
Cartographier les compétences mobilisées sur Analyse Basket et définir un plan de montée en compétences adapté à un projet majoritairement solo.

## Contexte
Le projet est réalisé seul. Le porteur du projet couvre la majorité des domaines (produit, développement, infrastructure, exploitation, documentation) avec appuis ponctuels de pairs pour challenger certaines décisions.

## Compétences mobilisées
- Angular
- TypeScript
- Angular SSR
- NestJS
- MongoDB / Mongoose
- PostgreSQL
- Drizzle ou ORM utilisé (à confirmer)
- Docker
- Docker Compose
- Traefik
- GitHub Actions
- GHCR
- CI/CD
- Monitoring Uptime Kuma
- Prometheus/Grafana (en cours/à terme)
- Sécurité web
- Accessibilité
- Documentation technique
- Gestion de projet
- Analyse métier sportive

## Compétences acquises ou renforcées
- Pilotage multi-repos.
- Orchestration infra Docker/Traefik.
- Conception de flux auth et stockage métier.
- Structuration documentaire orientée exploitation.

## Compétences à consolider
- Sécurité OWASP avancée.
- Audit dépendances.
- Scan images Docker.
- Backup/restauration BDD.
- Prometheus/Grafana avancé.
- Logs centralisés.
- Kubernetes futur.
- FFmpeg extraction vidéo.
- RGPD vidéo.
- Tests e2e et couverture.
- UX onboarding.

## Besoins futurs
- Renforcer la validation métier externe.
- Structurer des rituels de revue qualité/sécurité.
- Préparer une montée en charge technique et organisationnelle.

## Plan de développement des compétences
- **Court terme** : sécurité, backup, rollback, tests.
- **Moyen terme** : monitoring avancé, e2e, logs structurés.
- **Long terme** : Kubernetes, FFmpeg, RGPD vidéo, scalabilité.
