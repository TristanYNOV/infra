# Documentation Projet Analyse Basket (Infra)

## Objectif du document
Centraliser la documentation de référence du projet **Analyse Basket** pour le suivi produit, l’architecture technique, l’exploitation et la transmission de connaissances.

## Rôle du dossier `docs`
Le dossier `docs/` sert de base documentaire professionnelle unique pour :
- le cadrage et la gouvernance projet ;
- la description de l’architecture applicative et infrastructure ;
- les pratiques de développement, qualité, sécurité et accessibilité ;
- l’exploitation en production (MCO, monitoring, incidents) ;
- la documentation des parcours utilisateur.

## Organisation par domaines
- `cadrage/` : vision, besoins, risques, priorités.
- `architecture/` : vues techniques et flux applicatifs.
- `developpement/` : pratiques d’ingénierie et qualité.
- `exploitation/` : déploiement, supervision, maintenance.
- `pilotage/` : organisation, arbitrages, suivi.
- `utilisateur/` : guides d’usage et parcours.
- `utils/` : templates et checklists opérationnelles.

## Table des dossiers et objectifs
| Dossier | Objectif |
|---|---|
| `docs/cadrage` | Formaliser le besoin métier et le cadre projet |
| `docs/architecture` | Décrire la conception logicielle et infra réelle |
| `docs/developpement` | Standardiser les pratiques de dev et de test |
| `docs/exploitation` | Outiller le déploiement, la supervision et le support |
| `docs/pilotage` | Piloter délais, risques, arbitrages et communication |
| `docs/utilisateur` | Accompagner les utilisateurs sur les parcours clés |
| `docs/utils` | Fournir des modèles et checklists réutilisables |

## Documentation de suivi, exploitation et transmission
Cette documentation est utilisée simultanément pour :
- le **suivi projet** (avancement, décisions, arbitrages),
- l’**exploitation** (déploiement, incidents, monitoring),
- la **transmission technique** (onboarding, maintenance, continuité).
